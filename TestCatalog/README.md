# 3E Test Catalog

ارفع مجلد `TestCatalog` كاملًا إلى مسار عام يستخدم HTTPS، مثل GitHub Pages أو مستودع GitHub عام باستخدام روابط Raw.

أدخل داخل 3ELocal رابط ملف `catalog.json`. الروابط النسبية داخل الفهرس ستُحل تلقائيًا بالنسبة إلى مكان الملف.

هيكل النشر:

```text
TestCatalog/
├── catalog.json
├── icons/
│   └── hello3e.png
└── packages/
    └── Hello3E-v1.2.0.3eweb
```
